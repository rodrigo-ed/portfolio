# Portfolio RodrigoDev

Este é um projeto do meu portfólio pessoal desenvolvido por mim, estudante de Análise e Desenvolvimento de Sistemas, com foco em desenvolvimento Full Stack e análise de dados.

## Funcionalidades

- **Home:** Apresentação com foto, nome e botões de navegação.
- **Sobre:** Informações sobre formação, habilidades e trajetória.
- **Projetos:** Cards dinâmicos com descrição, links para GitHub e deploy (quando disponível).
- **Contato:** Informações de contato e formulário integrado ao WhatsApp.
- **Navbar responsiva:** Menu hamburguer para dispositivos móveis.
- **Layout totalmente responsivo:** Adapta-se a desktops, tablets e celulares.

## Tecnologias Utilizadas

- HTML5
- CSS3 (incluindo Flexbox, variáveis CSS e media queries)
- JavaScript (interatividade e manipulação de DOM)
- Font Awesome (ícones)

## Responsividade

- **Mobile:** Foto da home acima do nome e botões; foto da seção "Sobre" oculta.
- **Tablet:** Layout em coluna; foto da seção "Sobre" também oculta.
- **Desktop:** Layout em linha; todas as imagens visíveis.
